# Familiekalender

Mobilvennlig ukeoversikt for familiens aktiviteter og gjøremål.

## Funksjoner
- Rask registrering av aktivitet eller gjøremål
- Ukevisning og kommende hendelser
- Personfarger
- Redigering, sletting og ferdigmarkering
- Data lagres lokalt i nettleseren

## Neste steg
For at flere familiemedlemmer skal se og endre samme kalender på ulike enheter, bør appen kobles til innlogging og en delt database, for eksempel Firebase Auth + Firestore.
